Paprium on PC, version @VERSION@: notices

WHAT THIS IS

This folder holds no part of the game. On the player's PC, the launcher builds the game from the
player's own copy of the game file and keeps it in the player's own app-data folder,
%LOCALAPPDATA%\Paprium PC. In the words given, that output is
"a Patch copy of the Legally obtained rom".

Terms, as given:
  "gpl would apply to everything but the games rom itself the output your tool makes would still be partially their ip and cannot be sold."
  "sharing output is forbidden and not allowed just like sharing a rom"

About the name Paprium, as given: "there is no affiliation and no commercial use."

NOT IN THIS FOLDER

No part of the game. No Genesis Plus GX code and no Musashi code. Nuked-MD and FX68K were run in
simulation to measure how the chips behave; no code of theirs is in these programs.

No Sega BIOS, no TMSS code and no 32X or Mega CD code. For the consoles and Mega CD units of the
Console menu, the game program answers the game's own checks with only the few identification
words and bits the game compares, as the Pocket core does.
